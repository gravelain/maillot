# 📘 Glossaire DevOps

## restart: unless-stopped

Redémarre automatiquement un conteneur sauf si arrêté manuellement.

---

## healthcheck

Vérifie si un service est réellement prêt (pas juste démarré).

---

## volume bind mount

Dossier local relié à un conteneur pour persister les données.

---

## network docker

Permet aux conteneurs de communiquer entre eux sans exposer de ports externes.
